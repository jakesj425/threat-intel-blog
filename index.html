The litellm supply chain compromise is the one that should sting most. Datadog shows attackers used stolen GitHub CLI OAuth tokens to inject into the release pipeline and drop a Python infostealer that runs on every interpreter start via `.pth` and `sitecustomize.py`. The payload targets cloud creds, AI tool sessions, browser secrets, and LiteLLM proxy config; cleanup requires manually deleting dropped files because removing the package won't help. This is the second LiteLLM hit in 2026 (TeamPCP-linked earlier). The lesson isn't "don't install packages" - it's that release pipelines need branch locks and token hygiene because developer CLI tokens are now crown jewels.

Two different camps are showing how AI is changing offense. Symantec caught "Skynet", an autonomous agent hunting exposed LLM endpoints to power scanning/exploitation/mining, with jailbreaks to strip refusals and 74 tools to hit frameworks/Prisma/Werkzeug/debuggers. Meanwhile Zscaler tracked a global, AI-assisted campaign using a customized ARTEX framework with Claude Code/Codex/Grok, role-based agents reviewing each other's work, project state persisted across sessions, and a jump server to route through. Both are pointing the same direction: agents can sustain long-running ops and route through stolen/abused inference, shifting cost to victims while keeping operators more hands-off.

Vuln exploitation remains relentless at the edge. ClingSTUN is turning vulnerable edge devices into attacker infra (32 CVEs in the pulse alone). NetScaler is seeing active intrusions chaining CVE-2026-88771/88779 with multiple reports calling out exploitation. BeyondTrust Remote Support has CVE-2026-102764 actively exploited (ARMORY CASTLE tied). Cisco FMC vulns are under active exploitation with multiple state-aligned actors (UAT-12197/11823/11988, Sandworm). PAN-OS CVE-2026-0257 exploitation is ongoing. Artifactory is hit with a zero-day chain. AhsayCBS flaws exploited for webshells/XMRig. The theme: scan once, exploit broadly, pivot from edge/management planes.

Source: unit42.paloaltonetworks.com

Supply chain and initial access keep evolving. LiteLLM again; Midnight Mimosa exploiting Android firmware supply chain; a trojanized Terraform provider tied to TraderTraitor; Wazza device code phishing kit targeting M365; LLMjacking from stolen cloud billing to abuse inference. DPRK/Kimsuky remain active (Ukrainian targets, GitPower, Android supply chain). Ransomware crews (The Gentlemen, DragonForce) continue to professionalize.

Sources: sentinelone.com, acronis.com

For defenders: treat AI infra as exposed attack surface (lock down unauthenticated LLM/MCP endpoints, monitor spend), harden release pipelines (token scoping/branch restrictions), focus on edge/management plane (inventory, patch aggressively, hunt for unusual builds like the HAProxy tradecraft we saw previously), and instrument for AI-assisted TTPs (multi-session persistence, role-based agents, automated pivots). The gap between offense and defense is growing as agents industrialize tradecraft.

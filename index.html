1. Zero-Day Exploitation of Vulnerability (CVE-2026-20245) in Cisco Catalyst SD-WAN Manager

Actor: Unknown

1. Mandiant documents a nation-state-adjacent intrusion targeting Cisco Catalyst SD-WAN Manager at a service provider. The actor achieved initial access via rogue peering connections using stolen certificate material (likely from an earlier compromise), then exploited CVE-2026-20245 to escalate from a compromised admin account to root through a malicious CSV upload. The anti-forensic discipline here is notable: the actor backed up and restored modified config files, deleted the exploit artifact, and ran a validation script to confirm all traces were removed. SD-WAN controllers are increasingly targeted as 'living off the edge' targets — these devices operate as a black box with limited telemetry. The related CVEs CVE-2026-20127 and CVE-2026-20182 affect peering authentication and may have been used in earlier access. Prioritize patching to the fixed releases and audit /var/log/auth.log for vmanage-admin SSH from unexpected external IPs.

Source: cloud.google.com

2. What Is the BabaDeda Loader? Analysis of a New ClickFix Malware Campaign.

Actor: Unknown

2. Morphisec's analysis shows a significantly evolved BabaDeda loader using ClickFix social engineering to initiate a multi-stage chain. The chaining of hidden PowerShell, in-memory shellcode via Donut/pe2shc, DLL sideloading, and external payload storage in List.Control.dat is designed specifically to defeat file- and signature-based detection. The callback-based execution via legitimate Windows functions and region checks that exit on Russian/Belarusian systems indicate a targeted but operationally cautious actor. Delivery includes DanaBot and SectopRAT as final payloads. The infection chain leaves minimal disk artifacts — defenders should monitor for mshta.exe spawning PowerShell with hidden windows and look for unexpected child processes under svchost.exe.

Source: morphisec.com

3. Prinz Eugen ransomware: a deep dive into a new Go-based encryptor

Actor: ROOTBOY

3. ThreatDown's deep-dive on ROOTBOY's Go-based ransomware reveals a technically deliberate encryptor with notable anti-forensic design. ChaCha20-Poly1305 with Argon2id-to-HKDF KDF, per-file random IVs, and chunked 1MB encryption show competent implementation. The ordering (most recently modified files first) maximizes psychological pressure by encrypting actively-used documents before older, likely-backed-up data. The absence of a ransom note on disk and the self-delete via cmd.exe ping-delay trick reduce forensic recovery opportunities. The use of RemotePC RMM for staging and the 'germania' backdoor admin account indicate hands-on-keyboard post-exploitation. The ROOTBOY/avtokz attribution trail through XSS and Exploit forums connects this encryptor to a known data seller with a history of selling 700Credit data. Monitor for RMM tool abuse combined with net user additions using German-themed passwords.

4. Millenium: A RAT Rewritten, A Threat Multiplied

Actor: Y2K Operators

4. Group-IB tracks Y2K Operators operating Millenium RAT v4 as a MaaS operation with over 62,000 compromised endpoints across 160+ countries. The shift from .NET to native C++ removes framework dependencies while Telegram bot C2 provides free, resilient infrastructure that blends with legitimate traffic. The actor targets other cybercriminals by trojanizing XWorm and AsyncRAT builders — watch for compromised RAT operators as a secondary victim population. PDF lures in Russian language proxy Telegram API requests through mcdir.me, and post-execution filenames impersonate Windows processes (svchost.exe) or antivirus products to evade casual inspection. Block Telegram API endpoints on non-browser, non-messaging hosts and alert on UAC prompts from 'Windows Command Processor' that the user did not initiate.

5. KimJongRAT Continues to Evolve by Leveraging LOTS

Actor: Kimsuky

5. Kimsuky continues to evolve KimJongRAT with significant operational improvements. The shift from hardcoded C2 addresses to runtime retrieval from Google Drive means the malware does not need rebuilding when infrastructure rotates — this reduces the defender's window of opportunity after C2 takedown. The addition of MeshAgent RMM installation provides a backup persistence channel if the primary malware is detected. The delivery chain abuses GitHub Releases for initial file hosting and Google Drive for stage-two payloads, both trusted services that evade network allowlist controls. The use of AES encryption for on-drive payloads and RC4 for C2 URL protection shows deliberate defense-in-depth. The GitHub repo was taken down within days but a new one appeared within 96 hours — this is an active, well-resourced campaign with rapid rebuild capability.

6. ClickFix campaign delivers macOS infostealer via DMG

Actor: Unknown

6. Unit 42 reports a ClickFix variant targeting macOS users that mounts DMG images in the background without user interaction to deploy an infostealer focused on cryptocurrency wallet data. This is notable because macOS users have historically been treated as lower-risk targets, and the invisible DMG mount technique bypasses the visual cues that typically alert users to removable media mounting. The attack chain starts with a fake CAPTCHA prompt in the browser instructing the user to paste a terminal command — a behavioral social engineering pattern that has become the dominant initial access vector for macOS malware in 2026. Defenders should monitor for unexpected disk images appearing in system profiler output and alert on browser-initiated terminal commands.

7. AsyncRAT and Remcos Delivered in Multi-Stage Phishing Campaign

Actor: Unknown

7. LevelBlue SpiderLabs tracks a widespread multi-stage phishing campaign delivering AsyncRAT and Remcos through Excel macro attachments. The chain uses URL shorteners, Cloudflare Workers domains, and PNG steganography to hide payloads — the 'Fiber.Program' namespace is a consistent hunting marker across variants. The HTA filenames use a distinctive motivational-word-salad pattern ('goodthingswithbetterworldcoming.hta') that serves as a high-fidelity detection signal. The campaign affected manufacturing, media, professional services, agriculture, and chemical sectors globally in English, Polish, Chinese, and Thai language lures. The consistent use of the Fiber.Program.Main namespace and 'IN-/-in1' delimiters in PNG files provides reliable hunting queries. The threat actors likely use LLMs to generate the large number of obfuscation variants observed — defenders should treat this as an indicator of automation, not sophistication.

8. LokiBot After a Decade: An Analysis of a Recent LokiBot Campaign

Actor: Unknown

8. LevelBlue SpiderLabs demonstrates that LokiBot — a decade-old infostealer — remains operationally relevant through multistage delivery. The JScript-to-PowerShell-to-.NET injector chain running through aspnet_compiler.exe (a LOLBin) shows that the malware's longevity comes from evolving delivery rather than the payload itself. The 3DES-encrypted C2 config in the 'x' data section and API hashing for import resolution are long-documented but still effective against static analysis tools. Notably, the registry persistence mechanism is broken in custom-builder samples (writes to a C2-named key instead of Run), which reduces but does not eliminate the infection's stickiness. The reference to CVE-2026-24190 remains unconfirmed in context. LokiBot primarily targets browser credentials, crypto wallets, and email/FTP clients — credential hygiene and MFA remain the primary defenses against this decade-old threat.

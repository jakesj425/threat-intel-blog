Opinion of a DFIR Guy

TL;DR
  • 9 reports analyzed — 4 Malware Loaders & Backdoors, 3 Social Engineering & Malvertising, 1 Infrastructure & IoT Threats
  • 3 adversarial groups identified
  • 25 CVEs in active use
  • Top report: Threat Spotlight: The Jalisco Toolkit and AI-Powered Phishing Surge

1. I've been reading threat reports for about fifteen years, and this is the first week where I'd say the dominant theme is agents writing code for other agents. Four out of nine reports this cycle involve AI being used to develop, deploy, or control malicious operations. Not in the "maybe someday" sense, but in right-now production attacks.

2. The hunt.io report on Chinese operators using Claude Code and DeepSeek to breach government systems across four countries is one of the most sobering reads I've had this year. Thirteen Hong Kong-based servers, an open directory with source code, and the operators used Claude Code for execution and DeepSeek-v4-pro for attack logic. Government systems in Afghanistan, Thailand, and Taiwan were hit. Financial firms across Europe, Australia, and Asia. The operators deployed TencShell implants, SQL injection, Laravel deserialization — nothing novel TTP-wise, but all powered by AI-generated attack logic. The fact that they left an open directory with all this evidence is a classic self-own, but that shouldn't distract from how effective the approach was.

3. The Patriot Bait story from Trend Micro is almost comic in its audacity. bandcampro, a Russian-speaking actor with eight dental clinic computers under his control, used Google Gemini CLI to migrate and deploy a C&C botnet in six minutes. AI handled 89% of the work. The entire C&C infrastructure fits in 5KB across three plain text files. The AI proactively suggested improvements 59 times. That's wild. This wasn't a sophisticated APT with a budget; it was one guy in front of a terminal saying "make me a botnet" and the AI building it. The barrier to entry is gone.

Source: trendmicro.com

4. The TuxBot v3 story from Unit42 is where the flaws of LLM-generated code become apparent. A modular IoT botnet compiled for 17 architectures with a Go-based C2, OpenDNS DGA, IRC fallback, peer-to-peer gossip — but several features are broken due to LLM bugs shipped without manual review. It's like the security version of the uncanny valley: the code looks right, the structure is there, but it collapses under scrutiny. This is going to be a pattern we see more of — fast development, slow debugging.

5. On the supply chain side, Miasma v3's return to npm is significant. Four AsyncAPI packages compromised through the project's own GitHub Actions workflow with valid provenance attestations. That's the real story: OIDC integration and trusted publishing are good for security in general, but if the workflow itself is breached, provenance means nothing. The payload downloads from IPFS and plants a Node.js backdoor. This is the second major npm supply chain attack in a week (jscrambler was July 11), and both use the same pattern: compromise the release pipeline, not the code.

6. APT37 is back with NarwhalRAT, a Python-based RAT targeting Korean users through MS-themed spear-phishing. Dual C2 with Korean relay servers and pCloud as dead-drop resolver. Anti-VM, keylogging, audio capture — the full suite. Genians keeps turning out high-quality APT37 analyses (Capsule Vault last week, now this) and the pattern is consistent: cloud-based C2, Korean-focused targeting, phishing as initial access.

Source: genians.co.kr

7. On the bread-and-butter side, the Huntress terminal server phishing stager exposé is worth reading for the human element. A Romanian actor compromised a terminal server and used it to send 8.9 million emails via Gammadyne Mailer. The project file name was "dracii" — the devils. 666 threads. Phishing for Boots UK customers, with the kit hosted on a compromised Bolivian government website (ipelc.gob.bo). It's not sophisticated, but it worked. Huntress responsibly reported to Bolivia's CSIRT.

8. LabubaRAT and Jalisco round out the picture: Rust-based RAT masquerading as NVIDIA (DNS tunneling, SOCKS5), and a device-code PhaaS toolkit that provisions fresh OAuth codes in real time.

9. What I'd tell any security team this week: start treating AI models like you treat Docker images. If you don't know what it's doing and where it came from, don't run it. The threat actors aren't asking permission.

🔥 DFIR Dust-Up: npm Gets Shredded, macOS Meets DPRK, and Telegram Becomes C2 🔍

🔗 Thing #1: Sapphire Sleet weaponized Apple's own Finder to bypass macOS security. BlueNoroff/UNC1069 is hitting VC and Web3 firms on macOS — but the trick is using Apple Script Editor and Finder to execute code outside security boundaries. Victims run a fake Zoom SDK update, and Finder silently spawns bash. For DFIR: look for `osascript` spawning from Finder and unsigned binaries executing from updater workflows. Your EDR won't flag this as malware. Source

🔗 Thing #2: Mini Shai-Hulud turned `npm install` into a compromise vector. This supply chain attack hijacked LeoPlatform npm packages, GitHub Actions, AND Go modules. The `binding.gyp` file executes at install time — before the package even loads. They steal npm tokens, GitHub tokens, SSH keys, and AI coding assistant configs, then use GitHub orphan branches as dead-drop C2. For DFIR: audit CI/CD for packages with suspicious `binding.gyp` or postinstall hooks. Source

🔗 Thing #3: Millenium RAT rewrote in C++ and hides C2 inside Telegram Bot API. Developer "ShinyEnigma" sells it as MaaS for $50-90. Y2K Operators have infected 62,000+ endpoints across 160 countries — 39,730 in Q1 2026 alone. The Telegram C2 means no dedicated server to sinkhole. For DFIR: hunt for Telegram bot token patterns in memory dumps, not domain blocklists. Source

🔗 Thing #4: Photo ZIP campaign "laundered" authentication through Calendly and Google. Targeting hotels across Europe and Asia with photo-themed ZIPs containing malicious LNK files → PowerShell → Node.js implant. They bounce phishing through Calendly booking pages and Google redirects to bypass email security. For DFIR: your SEC logs show "trusted sender." Look for LNK files spawning encoded PowerShell and Node.js on weird ports. Source

The big picture? Supply chain is the new front door. npm packages, GitHub Actions, bot APIs — attackers aren't breaking in, they're getting invited through trusted pipelines. Your perimeter is now your package manager.

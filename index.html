🔥 DFIR Dust-Up: Crypto Gets Hijacked, npm Gets Shredded, and Turla Won't Quit 🔍

🔗 Thing #1: JINX-0164 turned LinkedIn into a crypto-killing machine. Posing as recruiters, they tricked devs into running AUDIOFIX (Python infostealer), then dropped MINIRAT (Go backdoor) to steal wallet keys. Then they trojanized `@velora-dex/sdk` on npm. Wild? They pivot from one dev endpoint straight into CI/CD. For DFIR: audit npm for unexpected dependency changes and watch LinkedIn DM attachments. Source

🔗 Thing #2: Sapphire Sleet weaponized Finder to bypass macOS security. BlueNoroff/UNC1069 hits VC firms — using Apple Script Editor to execute code outside security boundaries. Victims run a fake Zoom update, Finder silently spawns bash. For DFIR: look for `osascript` spawning from Finder. EDR won't flag this. Source

🔗 Thing #3: Mini Shai-Hulud made `npm install` a full compromise. Hijacked LeoPlatform npm, GitHub Actions, AND Go modules. `binding.gyp` executes before the package loads. They steal npm tokens, SSH keys, and use GitHub orphan branches as dead-drop C2. For DFIR: audit CI/CD for suspicious `binding.gyp` or postinstall hooks. Source

🔗 Thing #4: Millenium RAT hides C2 inside Telegram Bot API. Dev "ShinyEnigma" sells it as MaaS for $50-90. Y2K Operators infected 62,000+ endpoints. Telegram C2 means no server to sinkhole. For DFIR: hunt for bot token patterns in memory, not domain blocklists. Source

🔗 Thing #5: Photo ZIP campaign launders phishing through Calendly. Hotels targeted with photo ZIPs → malicious LNK → PowerShell → Node.js implant. They bounce delivery through Calendly booking pages to bypass email security. For DFIR: SEP logs show "trusted sender." Look for LNKs spawning Node.js on weird ports. Source

The big picture? Supply chain is the new front door. npm, GitHub Actions, LinkedIn DMs, bot APIs — attackers aren't breaking in, they're getting invited. Your perimeter is now your package manager, recruiter, and calendar app.

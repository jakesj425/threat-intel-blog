Opinion of a DFIR Guy

🔥 DFIR Dirty Dozen: This Cycle's Weirdest Finds That Deserve a Second Look 🔍

🔗 Thing #1: Edgecution escapes a browser sandbox with a Chrome extension. An IAB (Payouts King) is deploying Edgecution — a malicious Edge extension that abuses Chrome native messaging to break out of the browser sandbox entirely. From a DFIR perspective, this is wild: the thing runs a Python backdoor and a headless browser invisibly. Your EDR might see "just Chrome" while the attacker is executing arbitrary commands via websocket C2. Hunt for native messaging registry keys and suspicious extension manifests.

🔗 Thing #2: Cisco SD-WAN zero-day comes with built-in anti-forensics. CVE-2026-20245 is a privilege escalation via malicious CSV upload — but the kicker is the attacker systematically deletes files, restores configs, and runs validation scripts to wipe their own tracks. This is the kind of intrusion where you arrive and the logs are gone. The forensic gold is in the pre-exploitation peering anomalies and any surviving password file artifacts. If you run SD-WAN, check for unexpected user accounts yesterday.

🔗 Thing #3: KimJongRAT (Kimsuky APT) now dynamically fetches C2 from GitHub and Google Drive. A North Korean APT abusing GitHub Releases, Google Drive, and Dropbox as Living Off Trusted Sites (LOTS) infrastructure. The C2 isn't hardcoded anymore — it's fetched dynamically, so sinkholing one domain doesn't kill the campaign. For DFIR folks: your proxy logs will show "just GitHub traffic." The IOC is the pattern of GitHub API calls, not the domain.

🔗 Thing #4: Prinz Eugen ransomware uses ChaCha20 and leaves NO ransom note on disk. ROOTBOY's new Go-based encryptor is rad from a forensics standpoint: it scrubs memory, self-deletes, and does all extortion out-of-band via leak sites and email. No ransom note means no obvious "you've been hit" indicator. You'll find it by spotting the ChaCha20-encrypted file entropy and the missing notes. Targets include Standard Bank South Africa — big fish.

🔗 Thing #5: ClickFix now delivers macOS infostealer via fake CAPTCHA → DMG. The fake CAPTCHA → Terminal command pipeline has evolved to target Mac users with a self-signed DMG containing Atomic macOS Stealer (Odyssey variant). It trojanizes Ledger Live and Trezor Suite — replacing legit crypto apps with malware. For DFIR: check your users' Applications folder for duplicate Ledger.app bundles and suspicious LaunchAgents. The persistence is sneaky.

🔗 Thing #6: Cryptojacking via poisoned search results installs ScreenConnect persistence. This campaign is cool because it's dual-purpose: yes, they mine GPU coin, but they also install ScreenConnect RMM for persistent remote access. The DLL sideloading into Microsoft-signed .NET binaries means it looks legit in process lists. From an incident response angle: if you find XMRig on a workstation, don't just kill it — check for the ScreenConnect agent too, because the real payload is the backdoor, not the miner.

The big picture? The boundary between "commodity malware" and "targeted intrusion" is gone. Cryptojackers are installing RMM tools. Browser extensions are escaping sandboxes. Ransomware is going note-free. Assume every "simple" infection has a second, quieter stage.

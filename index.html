Opinion of a DFIR Guy

TL;DR

1. The big story this cycle is UAT-11795, a financially motivated Russian-speaking actor that Talos has done an excellent job tracking across two reports. They're deploying a custom RAT called Starland alongside a bespoke C2 implant called WLDR Agent, using trojanized installers for everything from Cisco AnyConnect to Zoom. The WLDR agent is the interesting piece — it's a Go-based HTTP implant that uses legit cloud services like Dropbox, Google Drive, and OneDrive for its command channel, making traditional C2 detection nearly useless. If your threat hunting relies on blocking suspicious domains, you're going to miss this one. The actor also deploys Castlestealer, a credential and crypto-wallet thief, and Remcos RAT. ClickFix lures are their primary delivery mechanism — fake CAPTCHA pages that copy malicious PowerShell to the clipboard. Talos calls this "The Patch Wars" and the name fits: UAT-11795 is actively iterating on their tooling, patching detection holes, and expanding. They're not going away.

2. The GoSerpent backdoor from Securelist (Kaspersky) tracks TetrisPhantom, a group targeting Southeast Asian government and diplomatic entities. GoSerpent is a Go-based backdoor with proxy capabilities, deployed alongside TMCLoader and Mimikatz. The use of Stowaway (a legitimate admin tool) for tunneling is a pattern I keep seeing — attackers love tools that blend into authorized admin traffic. The credential dumping via QuarkSdumpLocalHash is also notable: they're dumping LSASS via a custom technique rather than relying on stock Mimikatz, which shows they're aware of common detection rules.

3. Azure's writeup on the AsyncAPI npm compromise adds new details on the Miasma worm's evolution. The key finding is that the payload triggers at import time rather than install time, meaning `npm install — ignore-scripts` doesn't help you. The compromised packages published through AsyncAPI's own GitHub Actions with valid OIDC provenance — this is the same pattern we saw with jscrambler last week. Attackers are now targeting the build pipeline, not the source code. The BlueRabbit campaign connection to Gigawiper is an interesting data point I'll be watching.

4. HelloNet is a Chinese APT operation targeting Russian entities through the ViPNet update system via DLL sideloading. Government, energy, transportation, education, aerospace — a broad sweep of critical sectors. The implant suite includes HelloBackdoor, HelloInjector, HelloCleaner, and HelloProxy. The SSH tunneling via PuTTY and chisel-based C2 is well-executed tradecraft. This is a long-term espionage play, not smash-and-grab.

5. The Spirals ransomware case against an Asian IT company is textbook double-extortion: webshell, credential dumping, Chisel tunneling, Cloudflare Tunnel for persistence, and a Rust-based ransomware binary. The use of revsocks and ASP.NET webshells shows they had hands-on-keyboard access for a while before encrypting.

6. DragonForce abusing Microsoft Teams relays is clever and annoying. They're using TURN protocol relays (normally used for Teams media traffic) to tunnel C2 traffic, making it look like legitimate Teams connectivity. BYOVD with vulnerable drivers for privilege escalation.

7. On the macOS side, ClickLock Stealer from Group-IB is a paste-and-pwn ClickFix-style stealer targeting browser credentials and crypto wallets. It's part of an expanding macOS malware ecosystem — Cthulhu, Atomic, MacStealer, Banshee variants all in play. If your org runs Macs and you haven't locked down software installation, now's a good time.

8. The Steam wallpaper malware is a reminder that no platform is safe from infostealers. Lummma, Vidar, and DarkKomet distributed through Wallpaper Engine workshop items. 34 malicious wallpapers found. Users trusting workshop content is the vector, and it's a hard one to defend against when the platform is the distribution channel.

9. The TTF Lua loader campaign from Fortinet is a global phishing wave using TrueType font files to deliver a Lua-based loader via Donut shellcode. Fileless execution, Agent Tesla, Snake Keylogger, XWorm, Remcos. Casts a wide net and is hard to detect because the initial payload is a font file.

10. Potemkin Loader from Huntress rounds it out: ClickFix lures delivering a Go-based loader that fetches EtherRAT, with blockchain-based C2 and DGA. Creative, if impractical for scale.

11. For detection teams: if you don't have a baseline for your Teams TURN relay traffic, get one. Block unsigned macOS installers if you can. And check your GitHub Actions workflows for unauthorized branch commits — the supply chain attacks keep finding the same weak point.
